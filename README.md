# StopWatch

A simple stopwatch web app built with HTML, CSS, and JavaScript. It lets you start, stop, and reset a timer with a clean card-style interface and background image.

## Features

- Start the timer
- Pause/stop the timer
- Reset the timer to `00 : 00 : 00`
- Displays time in `HH : MM : SS` format
- Responsive, lightweight front-end design


## Run Locally

1. Open the project folder.
2. Double-click `index.html` in your file explorer, or
3. Serve it with a local web server such as:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## How It Works

- `script.js` manages the stopwatch logic and time updates.
- `style.css` provides the layout and visual styling.
- `index.html` contains the stopwatch display and action buttons.
